HOW TO USE

使い方

  1. DAWのボーカルトラックに挿入し、取り込みを開始。DAWを再生して対象箇所を流し、停止して解析します。
  2. キー・スケールを確認し、AUTO EDITの強さを選びます。黄色のAUTO REVIEWマーカーを聴いて確認します。
  3. A 原音 / B 補正後で比較し、ノートやカーブを手動調整。DAWのプロジェクトを保存して書き出します。

実画面は上の画面紹介で確認できます。デモ音源は権利確認後に掲載します。

INSTALL / DOWNLOAD

購入から、最初の起動まで。

会員登録・ログインは不要です。製品別受け取りページでSquare領収書URL・取引IDを入力すると、購入確認後にMac / Windows両版を取得できます。

macOS

公証済みDMGを開き、Standaloneの.appをApplicationsへコピー。AUの.componentは ~/Library/Audio/Plug-Ins/Components/、VST3は ~/Library/Audio/Plug-Ins/VST3/ に配置し、DAWを再起動・再スキャンします。

Developer ID署名・Apple公証・ステープル検証済みの配布物です。隔離属性を解除するコマンドは不要です。OSの警告が解消しない場合は、警告内容を添えてサポートへご連絡ください。

Windows

製品別受け取りページからSetup.exeを取得し、ファイル名と下記のSHA-256を確認して実行。VST3 / Standaloneを選択してインストールします。DAWの再スキャン後に利用します。削除はWindowsの「インストールされているアプリ」から行います。

Windows版は未署名です。SmartScreenの警告が出る可能性があります。公式の受け取りページから取得したファイルであることとハッシュを確認したうえで、表示される場合は「詳細情報」→「実行」を選択できます。セキュリティ機能を無効にする必要はありません。不明なファイルは実行せず、お問い合わせください。
