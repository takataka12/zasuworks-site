REAL PRODUCT UI

ノートを見ながら、耳で決める。

DAW内で動作しているZASU VOCAL EDITORの実画面です。下の部分拡大は同じ撮影画面の各操作領域を示します。

実機撮影の同一画面を部分拡大しています。ZASU VOCALプラグインやZASU DAWの画面ではありません。

いつもの制作に、もうひとつの道具を。

AUTO EDIT

NATURAL / STANDARD / STRONGを選び、ピッチ補正をまとめて実行。AUTO DRIFT・TRANSITION・AUTO REVIEWが調整と見直しを助けます。

ピッチ解析・自動補正

単独のボーカルを最大120秒取り込み、ノートを解析。キー・スケールを確認し、SMART AUTO FIXで補正します。

気になる音だけ手動で

ノートの上下ドラッグ・分割、ピッチカーブの制御点編集、Undo / Redo、A/B比較、DAWプロジェクト保存に対応します。

ZASU VOCALとは別製品です。EQ・コンプ・空間系FXをまとめたZASU VOCALの代替ではありません。単独ボーカル向けで、ノートの長さ・タイミング変更やフォルマント独立編集は未搭載です。Standaloneでは補正音の同期再生に制約があり、実用的な補正作業には対応DAW内のAU / VST3を使用してください。

HOW TO USE

使い方

  1. DAWのボーカルトラックに挿入し、取り込みを開始。DAWを再生して対象箇所を流し、停止して解析します。
  2. キー・スケールを確認し、AUTO EDITの強さを選びます。黄色のAUTO REVIEWマーカーを聴いて確認します。
  3. A 原音 / B 補正後で比較し、ノートやカーブを手動調整。DAWのプロジェクトを保存して書き出します。

実画面は上の画面紹介で確認できます。デモ音源は権利確認後に掲載します。

INSTALL / DOWNLOAD

購入から、最初の起動まで。

Squareの決済完了後、受け取りページへ進みます。購入時のメールアドレスでZASU ACCOUNTにログインし、購入管理から領収書URL・取引IDを追加。メールに届く確認コードで購入を登録すると、Mac / Windowsの両方を取得できます。

macOS

公証済みDMGを開き、Standaloneの.appをApplicationsへコピー。AUの.componentは ~/Library/Audio/Plug-Ins/Components/、VST3は ~/Library/Audio/Plug-Ins/VST3/ に配置し、DAWを再起動・再スキャンします。

Developer ID署名・Apple公証・ステープル検証済みの配布物です。隔離属性を解除するコマンドは不要です。OSの警告が解消しない場合は、警告内容を添えてサポートへご連絡ください。

Windows

購入管理からSetup.exeを取得し、ファイル名と下記のSHA-256を確認して実行。VST3 / Standaloneを選択してインストールします。DAWの再スキャン後に利用します。削除はWindowsの「インストールされているアプリ」から行います。

Windows版は未署名です。SmartScreenの警告が出る可能性があります。公式購入管理から取得したファイルであることとハッシュを確認したうえで、表示される場合は「詳細情報」→「実行」を選択できます。セキュリティ機能を無効にする必要はありません。不明なファイルは実行せず、お問い合わせください。
