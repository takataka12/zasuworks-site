3つの仕上げプリセット

MAX FINISH / ROCK BALANCE / NATURAL FINISHから選び、音源に合わせて調整します。

原音と比較しながら仕上げる

WAVを読み込み、書き出す

処理結果は音源・設定によって変わります。すべての音源の音圧や仕上がりを保証するものではありません。PCM書き出しでは安全のため音量が下がる場合があります。

HOW TO USE

使い方

  1. DAWにAU / VST3を挿入するか、StandaloneのPLAYERにWAVを読み込みます。
  2. プリセットを選び、A/B・ラウドネスマッチで原音と比較しながら調整します。
  3. DAWで書き出すか、PLAYERのEXPORTからFloat32 / PCM24で保存します。

実画面は上の画面紹介で確認できます。デモ音源は権利確認後に掲載します。

INSTALL / DOWNLOAD

購入から、最初の起動まで。

Squareの決済完了後、受け取りページへ進みます。購入時のメールアドレスでZASU ACCOUNTにログインし、購入管理から領収書URL・取引IDを追加。メールに届く確認コードで購入を登録すると、Mac / Windowsの両方を取得できます。

macOS

公証済みDMGを開き、Standaloneの.appをApplicationsへコピー。AUの.componentは ~/Library/Audio/Plug-Ins/Components/、VST3は ~/Library/Audio/Plug-Ins/VST3/ に配置し、DAWを再起動・再スキャンします。

Developer ID署名・Apple公証・ステープル検証済みの配布物です。隔離属性を解除するコマンドは不要です。OSの警告が解消しない場合は、警告内容を添えてサポートへご連絡ください。

Windows

購入管理からSetup.exeを取得し、ファイル名と下記のSHA-256を確認して実行。VST3 / Standaloneを選択してインストールします。DAWの再スキャン後に利用します。削除はWindowsの「インストールされているアプリ」から行います。

Windows版は未署名です。SmartScreenの警告が出る可能性があります。公式購入管理から取得したファイルであることとハッシュを確認したうえで、表示される場合は「詳細情報」→「実行」を選択できます。セキュリティ機能を無効にする必要はありません。不明なファイルは実行せず、お問い合わせください。
