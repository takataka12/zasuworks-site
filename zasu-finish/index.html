よくある質問

LOUDとの違いは？

LOUDは音圧と密度、FINISHは全体のバランスと質感。目的が違う別製品です。

返金はできますか？

7日間返金保証の対象外です。重複決済・配布不備など当方の責による場合は個別に対応します。

購入から最初の起動まで

会員登録・ログインは不要です。製品別の受け取りページでSquareの領収書URLか取引IDを入力すると、購入確認後にMac版とWindows版の両方を取得できます。

macOS
公証済みDMGを開き、Standaloneの.appをアプリケーションへコピー。AUの.componentは ~/Library/Audio/Plug-Ins/Components/、VST3は ~/Library/Audio/Plug-Ins/VST3/ に置き、DAWを再起動して再スキャンします。隔離属性を解除するコマンドは不要です。
Windows
Setup.exeのファイル名と下のSHA-256を確認して実行し、VST3 / Standaloneを選んでインストールします。Windows版は未署名のため、SmartScreenの警告が出た場合は「詳細情報」から「実行」を選べます。セキュリティ機能を無効にする必要はありません。
