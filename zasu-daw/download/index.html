02 / INSTALL

最初の準備は、シンプルに。

Macの場合

  1. ダウンロードしたDMGをダブルクリックします。
  2. 「ZASU DAW」を「Applications」へドラッグします。
  3. コピーが終わったら、アプリケーションフォルダーから「ZASU DAW」を起動します。
  4. 録音に使う場合は、マイクへのアクセスを許可します。

コピー後は、DMGのウインドウからではなく、アプリケーションフォルダー内のアプリを開いてください。

Windowsの場合

  1. ZIPを右クリックし、「すべて展開」を選びます。
  2. 展開したフォルダーを、ドキュメントなど分かりやすい場所に置きます。
  3. フォルダー内の「ZASU DAW.exe」をダブルクリックします。
  4. 詳しい設定は、同梱の「インストール方法.txt」をご覧ください。

ZIPの中から直接実行せず、展開してから開いてください。Visual Studioなどの開発ツールは不要です。

あとで再ダウンロードできますか？

はい。同じブラウザーでこの受け取りページを開くと、購入を再確認してMac版・Windows版を再ダウンロードできます。ブラウザーのデータを削除した場合や別の端末では購入情報が引き継がれないため、Squareの決済控えを添えてお問い合わせください。再購入は不要です。

購入したのにダウンロードできない場合

決済の反映に少し時間がかかる場合があります。「購入を再確認する」が表示されているときは、少し待ってから押してください。解決しない場合は、購入日時とSquareの決済控えを添えてお問い合わせください。再購入は不要です。

Windowsで起動時に警告が出ます

公式購入案内から入手したファイルであることを確認し、警告に「詳細情報」と「実行」が表示される場合は、その順に選択してください。実行できない場合や別の検出画面が出た場合は、表示内容を控えてお問い合わせください。保護機能全体を無効にする必要はありません。

音が出ない・録音できない場合

「入出力設定」の機器・入力チャンネルと48,000 Hzの設定、WindowsまたはMac側の音量とマイクのアクセス許可をご確認ください。録音するトラックや消音・ソロ、マスター音量も確認してください。

プロジェクトを移動・バックアップしたい

「保存」で作成した .zasu ファイルと、音声素材フォルダーを一緒に保管してください。「WAV書き出し」は完成音声の書き出しで、編集用プロジェクトの保存とは異なります。

本製品は開発中のBeta版です。大切な録音はこまめに保存し、元の素材も別に保管してください。
