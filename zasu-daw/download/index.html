02 / INSTALL

最初の準備は、シンプルに。

Macの場合

  1. ダウンロードしたDMGをダブルクリックします。
  2. 「ZASU DAW」を「Applications」へドラッグします。
  3. コピーが終わったら、アプリケーションフォルダーから「ZASU DAW」を起動します。
  4. 録音に使う場合は、マイクへのアクセスを許可します。

更新する場合は、プロジェクトを保存してZASU DAWを終了し、Applicationsへのコピー時に「置き換える」を選んでください。設定やプロジェクトを削除する必要はありません。コピー後は、アプリケーションフォルダー内のアプリを開いてください。

Windowsの場合

  1. 作業中のプロジェクトを保存し、ZASU DAWを終了します。
  2. ダウンロードした「ZASU-DAW-v0.0.14-Windows-Setup.exe」をダブルクリックします。
  3. 画面の案内に従ってインストールします。
  4. スタートメニューから「ZASU DAW」を起動します。

旧ZIP版をお使いの場合も、そのままインストールできます。更新後は旧フォルダーのEXEではなく、スタートメニューのZASU DAWを開いてください。既存のプロジェクト・音声素材・設定を削除する必要はありません。Visual Studioなどの開発ツールは不要です。

あとで再ダウンロードできますか？

はい。同じブラウザーなら保存した購入情報から再確認できます。別の端末やブラウザーのデータを削除した場合も、Squareの領収書URLまたは取引IDを上の「購入を復旧する」に入力してください。再購入は不要です。

購入したのにダウンロードできない場合

決済の反映に少し時間がかかる場合があります。「購入を再確認する」が表示されているときは、少し待ってから押してください。解決しない場合は、購入日時とSquareの決済控えを添えてお問い合わせください。再購入は不要です。

Windowsで起動時に警告が出ます

公式購入案内から入手したファイルであることを確認し、警告に「詳細情報」と「実行」が表示される場合は、その順に選択してください。実行できない場合や別の検出画面が出た場合は、表示内容を控えてお問い合わせください。保護機能全体を無効にする必要はありません。

音が出ない・録音できない場合

「入出力設定」の機器・入力チャンネルと48,000 Hzの設定、WindowsまたはMac側の音量とマイクのアクセス許可をご確認ください。録音するトラックや消音・ソロ、マスター音量も確認してください。

プロジェクトを移動・バックアップしたい

「保存」で作成した .zasu ファイルと、音声素材フォルダーを一緒に保管してください。「WAV書き出し」は完成音声の書き出しで、編集用プロジェクトの保存とは異なります。

大切な録音はこまめに保存し、元の素材も別に保管してください。
