AvatarLive

iPhoneだけで、Live2D配信まで。

TrueDepth / ARKitでLive2Dモデルをリアルタイムに動かし、録画から720p30のRTMP/RTMPSライブ配信までをiPhone単体で行うVTuber向けiOSアプリです。

iOSCubism SDK for NativeARKitRTMP / RTMPS720p / 30fps

できること

Live2Dモデルをインポート

利用権を有するモデルをZIPまたはフォルダから読み込み。model3.json / moc3 / textures / physics / pose / motions等に対応。

ARKitフェイストラッキング

顔の向き、瞬き、口の開閉をTrueDepthカメラから取得してLive2Dパラメータへリアルタイム反映。

iPhoneから直接ライブ配信

1280×720 / 30fpsの配信用キャンバスをH.264/AACで生成し、RTMP/RTMPS対応サービスへ送信。

録画・音声・背景

ローカル録画、外部マイク、Voice Gain、Photo背景、モデル位置・倍率の保存に対応。

配信までの流れ

01Import
02Track
03Render
04Encode
05Live
