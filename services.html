SERVICES

ZASU WORKSの中心は自社プロダクトですが、そこで得た実装・公開・運営の経験を使って、制作相談にも対応しています。

01 / MENU
What You Can Ask For

作りたいものを、
公開できる形へ。

最初から完璧な仕様書は必要ありません。「何を作りたいか」「誰が使うか」「いつ頃必要か」から整理できます。

iPhone / iOS

iPhoneアプリを形にする。

アイデア整理からSwift / SwiftUI実装、実機テスト、App Store公開準備まで。

  • アイデア・機能整理
  • 画面設計 / UI
  • Swift / SwiftUI実装
  • 実機テスト / 修正
  • App Store公開支援
Web / Cloud

Webサービスを公開する。

紹介サイトから、アップロード・処理・結果表示を持つWebサービスまで。

  • サービス設計 / UI
  • Webサイト / Webアプリ
  • バックエンド / クラウド
  • 独自ドメイン / 公開設定
  • 公開後の改善相談
Music / Audio

音を仕上げる。道具も作る。

音楽制作の実体験を活かし、Mix / MasteringからAudio系ツールまで横断して対応。

  • Mix / Mastering
  • 音源・音声処理
  • 音楽系アプリ企画
  • Audioワークフロー
  • 音楽向けWebサービス
