## 1. 目的と承認範囲

写真と製品画面を見れば「VOCALで歌を整える → LOUDで仕上げる → セットで買える」が伝わる、スマートで高級感のある音楽ソフトブランドサイトへ仕上げる。

承認された方向は、写真中心のHero、大きなVOCAL／LOUD実機画面、¥5,980セットへの自然な導線、短い説明と大きな余白。主役と順序はVOCAL → LOUD → 歌ってみた制作セット → DAW → AUDIOを維持する。

本書は既存トップページの表示改善に限定した設計であり、新しいサービス構成や購入システムの設計ではない。この段階で許可されている作業は指定3点の読み取り確認、設計書の更新・commit・提示まで。commit対象は設計書だけとし、本番実装・push・deployは行わない。実装計画には本書の修正結果を提示した後、ユーザーの指示を受けて進む。

正本は既存サイトと `takataka12/zasuworks-site`。設計時のローカルHEADは `e47d7573aec8f99fd7764de97607dedc3643ac00`。設計書作成時にリポジトリの未コミット変更がないことを確認した。直前の読み取りでは本番トップページと `index.html`、本番専用CSSと `assets/home-visual.css` の一致を確認している。

## 3. 共通ビジュアル

黒・チャコールを基調に、VOCALは抑えたグリーン、LOUDはイエロー／ゴールド、DAWはライム、AUDIOはブルーで識別する。色は見出し・短いラベル・CTAの強弱に絞り、全面的な発光や過剰なネオンを使わない。

連続する枠付きカードを、背景に溶け込むセクションへ置き換える。写真、製品UI、見出しの大きさ、上下の余白で場面を切り替える。公式ZWロゴと既存ブランド名を維持し、モックアップの簡略ロゴを新しい正式ロゴとして扱わない。

各製品の内容は製品名、短いコピー、実機UI、短い機能ラベル、価格、OS、CTA、再DLリンクで完結する。説明文の削減目標は現行比30〜40%。実装時は主コンテンツの説明・機能文章を対象に前後の文字数を比較し、価格・バージョン・OS・リンク・画像キャプション・法的情報を削減率のために消さない。

## 4. セクション設計

### Hero：音楽制作の瞬間を主役にする

採用するのは、暗いレコーディングスタジオで、ヘッドホンを着けた歌い手がコンデンサーマイクとポップガードに向かう承認済み写真。デザイン検討用に生成した写真素材であり、実在ユーザーの利用実績を示す写真としては説明しない。

主コピーは「歌を整えて、音圧を仕上げて、完成。」。長い導入文と4製品の説明一覧をHeroから減らす。直下にVOCAL／LOUDへの短いページ内リンクを置き、既存ナビゲーションからDAW／AUDIOにも到達できる状態を維持する。

Desktopでは写真の左側の暗い余白へコピー、人物とマイクを右側へ配置。Mobileでは人物・マイクを優先して写真をトリミングし、下部の薄い暗色グラデーション上へ2行程度のコピーを置く。コピーは画像に焼き込まずテキストとして表示する。

### ZASU VOCAL：歌声の解析画面を大きく

表示は「ZASU VOCAL」「v1.0.0 正式販売中」。コピーは「DAWは変えなくていい。歌だけZASUにする。」。

Logic Proで取得された実機画像 `zasu-vocal/assets/logic-pro-v1.0.0.jpg` を使用する。解析領域、Pitch／Note／Blob、Key／Scaleなどが見える範囲を主役にし、ホストの外周をCSSの表示範囲で整理する。UI内容や数値の描き替えは行わない。元画像は保持し、必要なら画像全体を商品ページで確認できる既存導線へ誘導する。

機能ラベルは「解析 / 自動補正 / ノイズ低減 / ミックス」。長いDSP・FX説明はトップへ再掲せず商品ページへ誘導する。¥3,980（税込・買い切り）、macOS Universal（Apple Silicon / Intel）、Windows x64を維持。CTAは「ZASU VOCALを見る」、既存の再ダウンロードリンクを併記する。

Mobileは見出し・コピー → UI → ラベル → 価格・CTAの順。Desktopはコピー・購入導線と、大きなUIの2列とする。

### ZASU LOUD：VOCALと対になる仕上げの場面

表示は「ZASU LOUD」「v2.0.0 正式販売中」。コピーは「音圧を上げる。迷わず、仕上げる。」。必要な補助コピーは「LOUDER. NOT WORSE.」。機能ラベルは「Loudness / True Peak / 密度」。

既存スタジオ写真を低い濃度で背景に使用し、実機UIのノブ・メーターを大きく見せる。VOCALと同じ箱を黄色に塗り替える構成は避け、背景と余白で対を作る。

今回確認できた真正なv2.0.0実機素材 `IMG_C716282D-6D04-4638-9BD7-DFF10BEC6670.jpeg` を優先する。これはWindows上で動作するLOUDの実機画面を撮影した写真であり、直接キャプチャしたスクリーンショットとは区別する。画像内の「ENGINE v2.0.0」と操作UIを目視確認した。原本の識別子は `libfile_1a85b113f2788191b05f8d207d7ba2c5`。実装時はプラグイン部分を大きく見せ、キャプションを「ZASU LOUD v2.0.0 / Windows実機撮影」とする。版番号・数値・操作部は描き替えず、元写真を保持する。真正な直接スクリーンショットが利用可能になった場合は、それを優先する。

旧 `assets/zasu-loud-v112.png` は予備素材に限る。旧版画像を使用する場合のみ「旧版参考画面：v1.1.2 / 販売版はv2.0.0」を明記する。生成したUIを実機画面として掲載しない。

¥2,980（税込・買い切り）、macOS Universal（Apple Silicon / Intel）、Windows x64を維持。CTAは「ZASU LOUDを見る」。再DLリンクも残す。Windows未署名とSmartScreen等の警告に関する商品詳細・FAQの既存案内を保持する。

## 5. MobileとDesktopの寸法方針

Mobileを優先し、320／375／390px、Tablet 768px、Desktop 1440pxで確認する。Mobileの左右余白は約20〜24px、主力製品間の余白は約32〜48pxを基準にする。見出しは約26〜32px、短いコピーは約18〜22px。補助文字は11px未満にしない。CTAは実効高さ44px以上を確保する。

390×844pxの表示を基準に、Hero → VOCAL → LOUD → セットを3〜4画面程度まで許容する。画面数は目安であり、写真の存在感、製品UIの判読性、余白、高級感を優先する。2〜3画面以内やセット価格・CTAの3画面以内到達を必須条件にしない。実装時は実測してスクロールの流れを確認するが、数値に合わせてUIを縮小したり、説明・CTAを詰め込んだりしない。

Desktopは最大幅を設けて過度な横伸びを防ぎ、主力製品をコピーとUIの2列で見せる。320pxでも横スクロール、価格とCTAの重なり、見出しの欠けが発生しないように折り返す。Mobileで重要内容を非表示にしてページを短くしない。

## 7. 画像・速度・アクセシビリティ

承認済みHero写真を軽量WebPとして用意し、既存の画像URLは上書き・削除しない。Heroは表示に必要な優先読み込み、下段画像は遅延読み込みを使用。各画像に寸法またはaspect-ratioを設定してレイアウトの跳ねを防ぐ。必要な画像の最適化はWeb掲載用に限定し、配布物には触れない。

装飾写真は空の代替テキスト、製品UIには内容と製品名が伝わる代替テキストを用いる。価格やOSを画像だけで提示しない。背景写真上の文字のコントラストとCTAのキーボードフォーカスを確認する。メニュー、スキップリンク、タップ操作を保持する。

初回実装は静止画と控えめなhoverを基本とし、Parallax・浮遊・スクロールアニメーションを追加しない。既存演出を残す場合も `prefers-reduced-motion` で停止できる状態を維持する。
