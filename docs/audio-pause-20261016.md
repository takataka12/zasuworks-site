# ZASU AUDIO 一時停止（2026-10-16）

経営判断により MIX / MASTER / MIX READY / CONVERT の新規受付・開発を停止する。再開は事業主の明示指示がある場合のみ。

## サイト変更
- トップ、製品一覧、製品比較と共通ナビゲーションを `/audio-status.html` の一時停止告知に変更。
- ZASU ACCOUNT、購入済み製品の受け取り・サポート・製品決済のURLとロジックは維持。
- 静的表示だけではAPI受付を停止できない。サーバー側の受付停止はSupabase / Railway側の運用記録で別途確認する。
- 本リポジトリのActionsは公式サイトのPages配信であり、共有製品を維持するため停止しない。

## 資産・再開手順
既存のソース、API実装、スキーマ、Git履歴は削除しない。認証情報は既存の秘密管理サービスから取得し、文書・バックアップには記録しない。

再開前に (1) 事業主の明示指示、(2) DB・ストレージ・処理エンジンと未完了注文の確認、(3) API受付・ジョブ・決済の安全なテスト、(4) 本コミットの対象表示と生成元を復元してビルド・検証、(5) 公開後の監視、の順に実施する。画面だけを先行して再開しない。

本番の実決済による検証は実施しない。
